# Successful-result IN

Research grade and not externally audited. The method-bound IN members call
this bounded membership check over the private row values authenticated by the
existing `result_m5` relation. The variable identifier and typed encoded constant
list are public and independently reconstructed from the receiver's query.

The selected variable must occur in an active pattern and remain unprojected.
Every active result row must match an active list entry; unused list entries
must be zero. The base relation authenticates the values and enforces pattern,
projection, result and status bounds.

Use the repository pins: nargo 1.0.0-beta.21 and bb 5.0.0-nightly.20260324.
From `zk/compose`, run `nargo test --package result_in_core`.
